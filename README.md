# # TP2 Flutter - Cardápio Digital
App Flutter de apresentação de produto (Burger Supreme) - projeto TP2 da disciplina de Desenvolvimento Mobile, Fatec Rubens Lara
Aplicativo desenvolvido em Flutter para representar a tela de um produto de restaurante.

## Funcionalidades

- Exibição do produto
- Nome e preço
- Avaliação em estrelas
- Descrição do prato
- Lista de ingredientes
- Controle de quantidade
- Adição do produto ao pedido
- Cálculo do valor total

## Tecnologias

- Flutter
- Dart
